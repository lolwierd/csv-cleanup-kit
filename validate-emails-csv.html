How to Validate Emails in a CSV (and Quarantine the Bad Ones)

One bad email per row can get your whole import rejected — or worse, tank your sender reputation. Here's the conservative check I run on every file, and why failures go to quarantine instead of the trash.

Step 1: find the email column

Don't hardcode the column index — real-world headers vary. Match case-insensitively against the usual names:

def find_col(header, *cands):
    low = [h.strip().lower() for h in header]
    for c in cands:
        if c in low:
            return low.index(c)
    return None

ci_email = find_col(header, "email", "e-mail", "email_address")

If none of those exist, rename your header to email and move on.

Step 2: test every address against one regex

This is the exact pattern from my cleanup script — deliberately conservative. It rejects garbage without rejecting real-but-unusual addresses:

import re
EMAIL_RE = re.compile(r"^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$")

ok = bool(EMAIL_RE.match((cell or "").strip()))

Strip whitespace before testing — "anna@mail.com " with a trailing space is a perfectly good address wearing a dirty coat.

anna@mail.com  ✓ valid after stripwhitespace is dirt, not damage

aaron.whitegmail.com✗ quarantinedmissing @ entirely
sales@shop✗ quarantinedno top-level domain
(empty)✗ quarantinednothing to send to

Honest limit: this checks shape, not deliverability. It can't tell you whether the mailbox exists — that needs a verification service. What it does is catch the typos and paste-errors that make up most list rot.

Step 3: quarantine, don't delete

The golden rule: a failed row goes to a separate quarantine file with the reason attached — never silently dropped, never "fixed" by guessing:

quar_rows.append(row + ["bad_email"])  # original row preserved + reason

Write it out with its own header:

csv.writer(f).writerows([header + ["quarantine_reason"]] + quar_rows)

On a recent 200-row demo file this caught 34 bad emails — every one listed with its reason, so the owner could eyeball mike@@gmail.com → mike@gmail.com by hand instead of losing the lead forever.
