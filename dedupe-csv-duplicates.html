How to Remove Duplicate Rows from a CSV (Exact-Match, Free)

A deterministic 2-minute recipe: keep the first copy of every row, drop the rest, and get a count of what was removed. Works on any CSV with a header row.

Option B: the 10-line version (understand the logic)

Exact-match dedupe is just "have I seen this row before?":

import csv

with open("leads.csv", newline="", encoding="utf-8-sig") as f:
    rows = list(csv.reader(f))

header, data = rows[0], rows[1:]
seen, clean, dupes = set(), [], 0
for r in data:
    if not any((c or "").strip() for c in r):
        continue  # skip fully blank rows
    key = tuple(r)          # the whole row, as-is
    if key in seen:
        dupes += 1
        continue
    seen.add(key)
    clean.append(r)

with open("leads-clean.csv", "w", newline="", encoding="utf-8") as f:
    csv.writer(f).writerows([header] + clean)

print(f"{len(data)} in, {len(clean)} out, {dupes} duplicates removed")

First occurrence wins, later copies are dropped, header row is preserved untouched.

The 3 gotchas Excel hides from you

GotchaWhat happensFix
John Smith vs john smithCounted as different rows (match is byte-exact)Lowercase + strip the columns you match on before comparing
anna@mail.com vs anna@mail.com  (trailing space)Counted as different rowsStrip whitespace from every cell first
Same email, different name spellingKept as separate rows (whole-row match only)Dedupe on a normalized-email key instead: email.strip().lower()

If your list came from two exports stapled together, gotcha #3 is usually where the real duplicates live. Match on the normalized email column, keep the first full row, and log every dropped address so you can audit it.

When NOT to auto-dedupe

  • Repeat buyers — two rows, same person, two different orders. Dedupe on email + order ID, not on the person.
  • Multi-event signups — same email at two webinars is signal, not dirt. Keep both or merge intentionally.
  • Any file without a header row — the script above treats row 1 as a header. Add one first.
